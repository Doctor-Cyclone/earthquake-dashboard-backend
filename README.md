# Earthquake Dashboard — Backend

Бэкенд дашборда землетрясений. Проект развивается поэтапно на Node.js и TypeScript.

## Текущий этап

Готовы HTTP-сервер и проверка работоспособности `GET /health`.
Подключение USGS, события землетрясений, кеш и фильтры запланированы на следующие этапы.

## Требования

- Node.js 24.11 или новее в ветке 24.x
- npm (поставляется с Node.js)

## Запуск

Откройте папку проекта в WebStorm и выполните в его терминале:

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:3000/health — сервер вернёт:

```json
{"status":"ok","service":"earthquake-dashboard-backend"}
```

`npm run dev` перезапускает сервер при изменении исходников. Остановка: Ctrl+C.
`npm start` запускает сервер без наблюдения за файлами.
`npm run check` проверяет типы TypeScript.
Node.js выполняет TypeScript напрямую; отдельная сборка не требуется.

## Настройки

По умолчанию сервер доступен только на этом компьютере: `127.0.0.1:3000`.
Чтобы изменить настройки, скопируйте `.env.example` в `.env` и поменяйте `HOST` или `PORT`.
Файл `.env` исключён из Git. Допустимый порт: целое число от 1 до 65535.

## API

| Запрос | Ответ |
| --- | --- |
| `GET /health` | `200`, JSON со статусом сервера |
| `HEAD /health` | `200`, без тела |
| Другой метод для `/health` | `405`, заголовок `Allow: GET, HEAD` |
| Неизвестный путь | `404`, JSON с ошибкой |

`/health` проверяет только работу сервера, а не доступность USGS.
