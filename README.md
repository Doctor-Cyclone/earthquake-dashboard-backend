# Earthquake Dashboard — Backend

Бэкенд дашборда землетрясений. Проект развивается поэтапно на Node.js и TypeScript.

## Текущий этап

Готовы HTTP-сервер, `GET /health`, подключение USGS и `GET /api/earthquakes`.
Кеширование и фильтры запланированы на следующий этап.

## Требования

- Node.js 24.11 или новее в ветке 24.x
- npm (поставляется с Node.js)

## Запуск

Откройте папку проекта в WebStorm и выполните в его терминале:

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:3000/health — сервер вернёт:

```json
{"status":"ok","service":"earthquake-dashboard-backend"}
```

`npm run dev` перезапускает сервер при изменении исходников. Остановка: Ctrl+C.
`npm start` запускает сервер без наблюдения за файлами.
`npm run check` проверяет типы TypeScript.
Node.js выполняет TypeScript напрямую; отдельная сборка не требуется.

## Настройки

По умолчанию сервер доступен только на этом компьютере: `127.0.0.1:3000`.
Чтобы изменить настройки, скопируйте `.env.example` в `.env` и поменяйте `HOST` или `PORT`.
Файл `.env` исключён из Git. Допустимый порт: целое число от 1 до 65535.

## API

| Запрос | Ответ |
| --- | --- |
| `GET /health` | `200`, JSON со статусом сервера |
| `HEAD /health` | `200`, без тела |
| Другой метод для `/health` | `405`, заголовок `Allow: GET, HEAD` |
| Неизвестный путь | `404`, JSON с ошибкой |

`/health` проверяет только работу сервера, а не доступность USGS.

## Данные землетрясений

`GET /api/earthquakes` получает [суточную ленту USGS](https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson).
Откройте http://127.0.0.1:3000/api/earthquakes после запуска сервера.
На этом этапе каждый запрос обращается к USGS; фонового обновления и кеша ещё нет.
Лента источника обновляется раз в минуту. Фильтры пока не поддерживаются.

Ответ содержит:

- `source`: `USGS`, `period`: `day`.
- `generatedAt`: время формирования ленты источником, UTC ISO 8601.
- `fetchedAt`: время получения и обработки данных нашим сервером, UTC ISO 8601.
- `count`: количество возвращённых землетрясений.
- `skippedCount`: количество пропущенных записей (некорректные или другого типа, например взрыв).
- `earthquakes`: события от новых к старым. Поля: `id`, `magnitude`, `place`, `time`, `longitude`, `latitude`, `depthKm`.

Магнитуда и описание места могут быть `null`. Глубина указана в километрах и может быть отрицательной.
Координаты не переставляются: longitude — долгота, latitude — широта.
`HEAD /api/earthquakes` выполняет ту же проверку источника без тела ответа.
При ошибке сети, тайм-ауте 10 секунд или некорректном формате ленты сервер возвращает `502`:

```json
{"error":"Earthquake data is temporarily unavailable","code":"UPSTREAM_UNAVAILABLE"}
```

## Проверки

```sh
npm run check
npm test
```

Автоматические тесты используют подставные ответы источника и не зависят от сети.
Они проверяют ошибки USGS, нормализацию, порядок координат, сортировку и HTTP-маршруты.
